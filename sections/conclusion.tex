\section{Conclusion}
Supplying execution feedback to a budget-constrained coding agent changes how it explores, but rarely what it delivers. Across 3,517 runs and realizations in Gemma 4 31B, advance check outputs halve replay on failing drafts, yet agents absorb saved calls into file reads and silent line-1 resets until hitting their cap. When checks expose counterevidence, six of seven feedback branches formulate an edit and every landed edit passes---while four hit the eight-call cap and 93 edit calls fail when delimiter corruption swallows \texttt{old\_string:}. Across 2,565 follow-up runs, prompt caps, retry rules, and \texttt{keep}/\texttt{reject} gates fail, showing that turning feedback into fixes requires runtime-reserved edit slots, resilient tool adapters, and state-bound rollback.
