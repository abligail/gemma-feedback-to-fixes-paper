# R01 公开行为核对口径

2026-10-14 固定；适用于 [protocol.md](protocol.md) 的共同初稿、一次公开检查、C/F 新会话续修。**这是公开轨迹标签，不是评分或测试正确性的认证。** 每题保留共同检查一条、C/F 各一条；覆盖固定 54 题，缺失也占一条。

## 阅读与记录

只读实际模型输入、公开题面/仓库材料、工具请求与返回、检查执行收据、冻结初稿、最终 `agent.patch` 和停止前工作树。**逐题评分、隐藏测试、参考修复及含评分的汇总不得进入本次核对。** 初稿/检查器的文字结论不能替代执行证据。

每条记录保留 task、branch、reviewer、reviewed_at、初稿/实际起点/检查/最终补丁身份及证据定位。每个确定标签至少给一个输入片段、工具事件或文件内容依据；跨事件判断给出前后位置。输出截断、文件缺失或不能分辨时标“未知”，不以无记录推断“未发生”。看过端点后若纠正事实，保留旧标签、时间及修改理由。

## 共同初稿与检查

| 项目 | 标签与判定 |
|---|---|
| 实际共同起点 | **一致 / 不一致 / 未知**。核实际应用的源码/文件内容及共享公开上下文，不能只看同题、同 seed 或声明的 hash。D 指冻结 `agent.patch`；沙箱终态另记。空补丁与初稿文件技术缺失分开。 |
| 反馈可得性 | **执行且可用 / 不可用 / 未知**。不可用原因保留：无检查、JSON/命令解析失败、初稿不可应用、执行故障/超时、改变交付源码、身份不明。保存真实执行与输出，即使本批不把它交给模型。 |
| 预期的公开依据 | **有支持 / 推断 / 无支持 / 未知**。核此前可见题干、文档、测试或调用者是否支持具体返回值、异常、边界和状态。仅写“依据 issue”、照抄当前实现输出或自造断言不算支持。 |
| 目标是否触达 | **触达相关行为 / 仅相关外围 / 未触达 / 未知**。核真实 checkout、导入/调用入口、输入与状态。只编译、收集零测试、mock 先失败或检查辅助副本不等于触达公开目标。异常可能正是 issue 所述，不机械归环境失败。 |
| 执行的语义 | **公开反证 / 与所检预期一致 / 无诊断力 / 未知**。“反证”须有公开支持的预期、实际触达和不符输出；exit 0 也可能反证，exit 1 也可能无关。“一致”只覆盖本次行为，不表示初稿正确；预期缺依据、只见退出码或缺关键输出时不能认证。 |

## 每支续修

| 项目 | 标签与判定 |
|---|---|
| 预先提供是否落实 | **真实结果已提供 / 明确未提供 / 明确不可得 / 不一致或未知**。读续修实际请求，确认命令、依据和预期一致；F 的结果属于共同初稿，C 的日志/文件没有提前暴露结果。截断导致信息丢失单记。 |
| 自行取得反馈 | **同检重新执行 / 其他相关检查 / 未执行 / 未知**。需工具返回及实际目标/预期；C 重取是合法行为，保留在主比较。只重复命令文字或说“我已验证”不算。 |
| 实际修改 | **源码已修改 / 仅检查或辅助文件改变 / 编辑失败 / 无修改 / 未知**。以成功工具结果及文件变化为准；“准备修复”、搜索替换未匹配不算源码落地。多种情况可按顺序并存。 |
| 与反馈的可见联系 | **针对反证修改 / 据已核查的一致结果保留 / 未见联系 / 未知**。须能把输出指出的问题与具体源码变化或明确保留决定对应；只有模型声称“按测试修好”不够。此标签描述可观察联系，不单独证明因果或修复正确。 |
| 检查是否漂移 | **未变 / 调用或环境修正 / 输入或覆盖改变 / 验收预期改变 / 未知**。预期改变再记 **有新公开依据 / 无新公开依据 / 未知**。输入或判据改变后的通过不能拼作原检查转绿；只有脚本文件名相同不算同检。 |
| 最终版本是否被检 | **同版本 / 检后又改 / 没有后续检查 / 未知**。以最后实际相关检查时的源码与最终提交补丁所表达源码比较，另记该检查的语义结果。提交后工作树再变另标；官方收集的 `agent.patch` 与停止前工作树不混算。hash 不同只证明版本不同，不证明语义退步。 |

同时抄录实际初稿/检查构造/执行/续修耗时、工具使用及取消/超时，注明阶段越限和初始化时间；不凭“150 秒”配置认定实际等预算。

## 冻结后再连接评分

先保存所有公开标签及证据，再连接 D/C/F 官方端点。只有两端都有正常评分时才标“通过→未过”“未过→通过”等转移；**无补丁、不可应用、技术未知、环境失败的转入/转出单列**，不伪装成已证实误改或纠正。完整 54 题保留，不事后删除 C 重取反馈、检查不可用或未遵循的题。

“有反证却未修改”“检查通过后又改源码”“公开检查一致但最终未过”分别是不同观察。某一行为与分差同时出现仍不足以证明它造成分差；不能用最终评分倒推公开预期有误、隐藏规则是什么，或把所有失败都叫无效测试。
